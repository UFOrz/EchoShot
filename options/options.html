② 默认模型

反推模型负责看图生成提示词，生图模型负责生成图片。在这里修改后，请点击“保存设置”。

③ 比例与尺寸

先选择常用比例；像素映射与图像质量可按需调整。

高级尺寸与质量使用默认值即可开始

像素尺寸用于 OpenAI 兼容接口及需要宽高的模型；其他平台会按所选比例和分辨率档位转换为各自支持的请求参数。

最终像素尺寸由所选平台和模型决定，可能与上方映射值不同；已知不支持的参数不会发送。

④ 配置备份重装或换设备时使用

导出或导入平台、模型、比例、语言和其他生成设置，方便重装插件或更换设备。

! 导出文件包含 API Key，请妥善保管，不要公开分享。
⑤ 图片本地备份自动备份、校验与恢复作品

生成图片保存到相册后，自动在所选目录的 EchoShot-backup 文件夹内备份成图、原图、角色与物品库及恢复清单。成图包含与相册下载一致的内嵌元数据，文件使用 SHA-256 校验。删除相册作品不会删除本地备份。

尚未选择目录

未完成项目保存在持久队列中，浏览器重启后会自动补齐；若系统收回目录授权，请重新授权。恢复不会覆盖相同 ID 的已有记录。目录授权不随配置导出。
